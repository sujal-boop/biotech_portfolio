# Sujal Nanda — Aspiring Biotechnologist

A static recreation with local images, stylesheet, and font files of the supplied portfolio page.

Open `index.html` in a browser to view it. No build step or package installation is required. The page uses the original hero and laboratory photographs and the Manrope font from Google Fonts.

The contact form validates the name, email, and message, then opens a prefilled email draft addressed to Sujal. It does not send the message automatically.
